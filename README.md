# Servidor-de-Descarga
Proyecto de Sistemas Operativos (UEES)

**Integrantes:** Anthony Martinez | Jorge Medina

**Descripcion:** Plataforma que gestiona múltiples solicitudes de descarga desde un servidor con capacidad limitada, administrando las conexiones activas y el registro del tráfico generado.

**Incio de la simulacion web: ** Para poder iniciar la simulacion se debe ir a la carpeta web.py, ahi es donde se cargara y estara en el puerto 8000 (*** http://127.0.0.1:8000 ***). Ahi se podra simular los casos cuando usuarios requieren entrar dentro de un servidor sus datos puedan ser: basicos o complejos y con o sin lockers
